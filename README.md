# Healthcare Supply Chain Analytics in Public Hospitals

## Project Overview
This project analyzes healthcare supply chain performance in public hospitals to improve inventory management, procurement efficiency, and operational decision-making.

## Objectives
- Analyze procurement performance.
- Monitor inventory levels.
- Evaluate supplier performance.
- Identify stock-out risks.
- Build interactive dashboards.

## Tools Used
- Python
- SQL
- Power BI
- Microsoft Excel
